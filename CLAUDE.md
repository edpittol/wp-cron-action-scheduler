## Agent skills

### Issue tracker

Issues live in GitHub Issues (`edpittol/wp-cron-action-scheduler`, via the `gh` CLI). PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix) — all map 1:1 to GitHub label names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
